# **Image Licenses -**

**Q. Can you use any image you find on your web page?**

**Ans :** Not by default. Images are considered **intellectual property**, which means they are protected by copyright regulations, most often belonging to the creator. By default, images are released as **all rights reserved,** meaning the creator, or sometimes the publisher, holds all copyright for the image.

## Using a Copyrighted Image

**Ans -** An all rights reserved image cannot be used on a web page unless one of three things is true -

### **1. Written Permission -**
Permission is obtained directly from the copyright holder.

### **2. A Purchased License -**
A license is purchased from the copyright holder.

### **3. Fair Use -**
The image is incorporated in a way that falls under fair use.

**NOTE :** Fair use requires that the use of the image is both **limited** and **transformative.** Commenting on or reviewing the art, or creating a parody of the image, are examples of fair use.

## Permissive Licenses

**Ans :** Some images are released under a permissive license, like a **Creative Commons** license, or the **BSD** license that freeCodeCamp uses.

• These images are available for use, but the license still needs to be read to understand the rules that come with it.

• For example, a license might require the website to be open source, or it may not permit the image to be modified at all.

## Public Domain

**Ans -** Some images are released to the **public domain.** An image under the public domain has no copyright attached to it, and is free to be used without any restrictions.

**NOTE :** Images licensed specifically under the **Creative Commons 0 (CC0)** license are considered public domain.

## Finding Images You're Allowed to Use

• Most search engines allow filtering image results by license.

• Sites like **Pixabay** and **Unsplash** offer free-to-use images.

---

Always be mindful of copyright and licensing when using an image on a website.

## Quick Recap

• Images default to all rights reserved - permission, a purchased license, or fair use is required to use them otherwise.

• Permissive licenses (Creative Commons, BSD, etc.) allow use, but come with rules that need to be followed.

• CC0-licensed images are public domain - free to use with no restrictions.

• Sites like Pixabay and Unsplash are good sources for free-to-use images.
