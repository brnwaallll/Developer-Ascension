# Developer-Ascension

A personal learning journal documenting my journey through web development fundamentals — one day, one topic at a time.

## About

This repository tracks my daily notes as I work through **HTML, CSS, and JavaScript** fundamentals, following freeCodeCamp's Responsive Web Design curriculum. Each entry breaks down a topic into clear explanations, code examples, and Q&A-style notes — written to reinforce what I've learned and to serve as a reference I can revisit later.

## Goal

To build a solid, self-taught foundation in web development — HTML → CSS → JavaScript → front-end libraries — and turn it into a visible record of consistent, hands-on learning.

## Status

🚧 In progress — actively updated as new topics are covered.
